🌿 Interactive Ghibli Portfolio

Welcome to my cozy, Studio Ghibli-inspired personal portfolio! This project is a visually appealing, responsive web card designed to feel like a breath of fresh air. It blends structured code with aesthetic warmth, featuring a soothing sage-green palette, an animated gradient background, and gently falling leaves.

✨ Features

Cozy Aesthetic: Sage-green accents and earth tones inspired by slice-of-life anime and nature.

Interactive Tabs: Clean, dynamic navigation between About, Education, Skills, and Hobbies sections without reloading the page.

Animated Environment: Features a CSS-powered ambient gradient background and a JavaScript-driven falling leaves particle system.

Fully Responsive: Beautifully adapts to mobile, tablet, and desktop screens using modern CSS Flexbox.

Lightweight: Built entirely with vanilla web technologies—no heavy frameworks required!

🛠️ Technologies Built With

HTML5: Semantic structure and layout.

CSS3: Custom properties (variables), Flexbox, hover transitions, keyframe animations, and glassmorphism effects (backdrop-filter).

JavaScript (Vanilla): DOM manipulation for tab switching and a custom particle generator for the falling leaves.

🎨 Customization Guide

Want to make it your own? Here are a few quick tips:

Profile Picture: Replace the src attribute in the <img class="profile-img"> tag with your own image URL.

Colors: Tweak the CSS variables in the :root pseudo-class (like --sage-green or --accent-color) to change the entire theme instantly.

Social Links: Update the href="#" attributes in the <div class="social-links"> section with your actual GitHub, LinkedIn, and Email links.
